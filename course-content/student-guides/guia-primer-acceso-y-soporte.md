# Guía de primer acceso y soporte

**Producto:** Automatiza tu Negocio en 7 Pasos  
**Audiencia:** estudiantes con acceso confirmado  
**Versión:** 0.1 — PARA REVISIÓN  
**Estado:** `BLOQUEADO_CONFIGURACION`  

> Esta guía queda lista para cargar en el LMS privado cuando se confirmen el canal de soporte y el plazo de primera respuesta. Los campos entre `{{llaves}}` no deben publicarse sin completar y probar.

## Empieza aquí

Tu acceso al curso debe llegar después de una compra confirmada o de una invitación autorizada para el piloto. Para comenzar:

1. abre el mensaje de acceso enviado por Language Center Chile;
2. entra mediante `{{enlace_acceso_alumno}}`;
3. crea tu propia contraseña si la plataforma lo solicita;
4. abre **Automatiza tu Negocio en 7 Pasos**;
5. completa **Bienvenida** antes de entrar al Módulo 1;
6. descarga una copia individual del workbook y guárdala en tu equipo.

No necesitas comprar nuevamente, crear una segunda cuenta ni compartir una contraseña para resolver un problema de acceso.

## Tu recorrido inicial

| Paso | Qué hacer | Resultado esperado |
|---:|---|---|
| 1 | Iniciar sesión con tu cuenta | Ves únicamente los cursos y recursos asignados a tu perfil. |
| 2 | Abrir `Bienvenida` | Comprendes la ruta, las reglas de práctica segura y el resultado del curso. |
| 3 | Descargar el workbook | Obtienes una copia que puedes editar sin cambiar el archivo original. |
| 4 | Completar la hoja `Ruta` | Registras un proceso, un resultado esperado y el Paso 1 como `En curso`. |
| 5 | Abrir `Módulo 1 · Diagnóstico y priorización` | Puedes continuar desde Bienvenida sin enlaces rotos. |

Si el Video 00 todavía aparece como `VIDEO PENDIENTE` dentro de una prueba privada, usa el texto de Bienvenida disponible y registra la incidencia. No debe reemplazarse por un video histórico con el nombre “7 Días”.

## Antes de pedir ayuda

Realiza estas comprobaciones una vez, en este orden:

1. confirma que estás usando el mismo correo al que llegó la invitación;
2. abre el enlace en la ventana normal del navegador, no dentro de la vista previa del correo;
3. actualiza la página e inicia sesión nuevamente;
4. comprueba que tu conexión permite abrir otras páginas;
5. prueba con una versión vigente de Chrome, Edge, Firefox o Safari;
6. si el enlace venció, solicita uno nuevo sin crear otra cuenta;
7. anota la hora, el navegador y el mensaje exacto del error.

No borres tu cuenta, no repitas el pago y no abras varias solicitudes por el mismo problema.

## Problemas frecuentes

### No recibí la invitación

- revisa Spam, Promociones y correos bloqueados;
- busca un mensaje de Language Center Chile con el nombre del curso;
- confirma que no estás buscando en una cuenta de correo distinta;
- solicita revisión indicando tu código `{{codigo_entrega}}`.

El equipo de soporte debe comprobar el estado de la misma matrícula antes de generar otra invitación.

### El enlace venció o no abre

- copia el enlace completo en una ventana normal del navegador;
- evita reenviar la invitación a otra persona;
- pide la renovación del enlace para la misma cuenta y matrícula;
- no publiques el enlace ni lo adjuntes en una captura.

### Puedo entrar, pero no veo el curso

- comprueba que tu perfil muestre tu nombre o identificador correcto;
- revisa `Mis cursos` o el panel equivalente;
- cierra sesión y vuelve a entrar una sola vez;
- informa el problema sin solicitar una cuenta nueva.

Soporte debe revisar la asignación del curso; no debe pedirte una contraseña.

### Veo el curso, pero un archivo no abre

- anota el nombre exacto del módulo y del archivo;
- indica si estás en computador, tableta o teléfono;
- prueba descargar una copia, sin editar el original compartido;
- registra si el error ocurre antes o después de la descarga.

No subas a soporte una copia del workbook que contenga datos personales, credenciales o información de clientes.

### Mi avance no se guardó

- vuelve a abrir el módulo y comprueba si la evidencia continúa adjunta;
- no marques una actividad como completada si falta su evidencia;
- indica el último módulo que viste, la hora aproximada y el estado esperado;
- evita repetir evaluaciones hasta que soporte confirme cómo continuar.

### El contenido solicita datos reales o acceso a producción

Detén la actividad. No ingreses contraseñas, bases de clientes, RUT, datos de pago, tokens, llaves API ni información confidencial. Registra el módulo y la instrucción observada para que se revise antes de continuar.

## Cómo contactar a soporte

**Canal pendiente de aprobación:** `{{canal_soporte}}`  
**Plazo de primera respuesta pendiente:** `{{sla_primera_respuesta}}`  

Usa un solo hilo por incidencia e incluye:

- asunto: `Acceso ATN7P · {{codigo_entrega}} · [problema breve]`;
- tu código de entrega, no el número de tarjeta ni datos del pago;
- módulo o pantalla donde ocurrió el problema;
- fecha y hora aproximada con zona horaria;
- dispositivo, sistema operativo y navegador;
- mensaje de error copiado literalmente;
- captura recortada y revisada, si es necesaria;
- lo que ya intentaste una vez.

### Formato seguro de solicitud

```text
Código de entrega:
Problema:
Módulo o pantalla:
Fecha y hora aproximada:
Dispositivo y navegador:
Mensaje de error:
Comprobaciones realizadas:
Resultado esperado:
```

## Información que nunca debes enviar

- contraseña o código de verificación;
- número de tarjeta, CVV o comprobante con datos visibles;
- RUT, documento de identidad o domicilio completo;
- credenciales de herramientas externas;
- bases de clientes o contactos reales;
- enlaces administrativos, cookies o tokens;
- capturas con correos, nombres o identificadores de terceros;
- el workbook completo si contiene información real.

Language Center Chile no necesita tu contraseña para comprobar una matrícula o un acceso.

## Qué ocurrirá después de tu solicitud

1. soporte registra una incidencia y conserva el mismo código de entrega;
2. revisa si el problema corresponde a invitación, matrícula, visibilidad, archivo o progreso;
3. solicita sólo la evidencia mínima que falte;
4. informa una acción concreta: reenviar invitación, corregir acceso, restaurar material o escalar;
5. confirma el resultado en el mismo hilo;
6. no crea una compra, cuenta o matrícula adicional salvo que exista una razón documentada.

Los tiempos internos de prueba no constituyen un SLA comercial mientras esta guía conserve el estado `BLOQUEADO_CONFIGURACION`.

## Recuperación segura

| Situación | Acción segura | Acción que debe evitarse |
|---|---|---|
| Invitación vencida | Revocar el enlace anterior y emitir otro para la misma matrícula | Crear una cuenta duplicada |
| Correo no recibido | Reintentar el mensaje sin cambiar el acceso válido | Volver a matricular |
| Curso incorrecto | Retirar la asignación incorrecta y probar la correcta | Borrar el historial |
| Archivo defectuoso | Volver a la última versión con hash verificado | Sobrescribir el original |
| Progreso inconsistente | Preservar evidencia y revisar el registro | Marcar módulos por el alumno |
| Acceso no autorizado | Limitar acceso, preservar evidencia y escalar | Ocultar o borrar el incidente |

## Criterio de publicación

Esta guía puede incorporarse al LMS privado únicamente cuando:

1. `{{enlace_acceso_alumno}}`, `{{canal_soporte}}` y `{{sla_primera_respuesta}}` tengan valores aprobados;
2. el recorrido Bienvenida → workbook → Módulo 1 funcione con una cuenta ficticia;
3. soporte reciba una solicitud de prueba y responda en el plazo aprobado;
4. la pauta docente no sea visible al rol estudiante;
5. la guía se revise en computador y móvil;
6. no existan datos reales, secretos o enlaces administrativos.
